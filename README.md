# BinderTracker

Tracker für meine Pokémon-Karten-Binder: der komplette Nationaldex (#1 bis #1025) als 4x4-Binderseiten, mit Seltenheit und Kartendesign pro Slot.

**Online:** https://pancodeforfun.github.io/BinderTracker/

## Funktionen

- Binder 1: #1 bis #640 (40 Seiten), Binder 2 ab #641 mit eigener Seitenzählung
- Suche nach deutschem oder englischem Namen oder Dex-Nummer, springt direkt zum Slot
- Pro Slot erst Seltenheit wählen, dann aus allen bekannten Karten dieses Pokémon die eigene antippen
- Übersicht aller Seiten, Statistik nach Seltenheit
- Speichert im Browser, Backup als JSON-Datei

## Lokal nutzen

`index.html` im Browser öffnen. Keine Installation nötig. Kartenbilder werden aus dem Internet geladen.

## Daten

- Pokémon-Namen und Bilder: [PokeAPI](https://github.com/PokeAPI)
- Kartendaten: [PokemonTCG/pokemon-tcg-data](https://github.com/PokemonTCG/pokemon-tcg-data), Bilder von images.pokemontcg.io
